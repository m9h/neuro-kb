# Research foundations and first readings

The question is whether a documented ASCL1/P19 preparation can produce a functional neural network that undergraduates can characterize and use in a controlled closed-loop task. These papers support different steps in that chain. Read the preparation-specific methods before importing a claim or timeline into this project.

| Priority source | What it contributes | What remains to establish locally |
| --- | --- | --- |
| [Farah et al., 2000 — bHLH neuronal conversion](https://pubmed.ncbi.nlm.nih.gov/10648228/) | P19 conversion by transient neural bHLH expression with E12; neuronal proteins and electrical excitability | Actual ASCL1 construct/delivery, conversion yield, maturation and synaptic network function |
| [Huang et al., 2015 — ASCL1 versus NEUROG2](https://pubmed.ncbi.nlm.nih.gov/25189318/) | Turner-coauthored comparison of inducible P19 lines; shared and factor-specific transcriptional programs | Whether the current method uses those lines/conditions; functional transmitter composition |
| [Visel et al., 2013 — forebrain enhancer atlas](https://pubmed.ncbi.nlm.nih.gov/23375746/) | McKinsey coauthorship; Figure 5C reports P19 luciferase assays with ASCL1 or DLX2 | Individual contribution and undergraduate chronology; reporter activity is distinct from neuronal function |
| [McKinsey et al., 2013 — Zfhx1b and interneuron fate](https://pubmed.ncbi.nlm.nih.gov/23312518/) | First-author neural fate study; Figure 5J and primary text describe DLX2-responsive P19 enhancer assays | DLX2 is a homeobox factor; this assay does not establish ASCL1-induced network maturity |
| [Functional synaptic transmission in P19-derived neurons, 1996](https://pubmed.ncbi.nlm.nih.gov/8558234/) | Functional synapse precedent in a published differentiated preparation | Synaptic transmission in the current ASCL1 preparation |
| [Takayama et al., 2009 — P19 ensemble recordings](https://doi.org/10.1541/ieejeiss.129.8) | Extracellular recording and synchronized bursting precedent | Reliable electrode coupling, artifacts, and evoked activity on the selected hardware |
| [Nakayama et al., 2014 — rapid adherent differentiation](https://pubmed.ncbi.nlm.nih.gov/24583076/) | Alternative preparation and functional-timing comparator | Head-to-head readiness comparison; use the same endpoint and time origin |
| [Kagan et al., 2022 — DishBrain](https://doi.org/10.1016/j.neuron.2022.09.001) | Reference sensory encoding, neuronal decoding and contingent feedback task | P19 substitution, independent cultures, frozen software, and matched controls |
| [Zhang et al., 2024 — Mind in Vitro](https://doi.org/10.1002/advs.202306826) | Open neural-interface platform architecture | Exact acquisition and stimulation path, delivered waveform and loop latency |
| [Aharoni and Hoogland, 2019 — miniscopes](https://pubmed.ncbi.nlm.nih.gov/30573833/) | Optical instrumentation context | Bench mounting, culture optics, indicator compatibility and timing alignment |

## How to record a reading

Write: question → preparation/method → measurement → result → limitation → project implication. Include the figure/page supporting each important statement and mark missing details as unknown. Use the experiment or independently initiated culture as the biological replicate where appropriate; frames, electrodes and spikes are technical/repeated measurements.

The Visel paper's relevant assay is **Figure 5C**, not Figure 3. The PubMed caption was checked against its figure heading on 30 September 2026. McKinsey's Zfhx1b paper has DOI **10.1016/j.neuron.2012.11.035**. The bibliography preserves these identifiers.
